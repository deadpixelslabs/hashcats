MINE A CAT

Your GPU searches real Keccak-256 nonces locally with WebGPU, using the same fast browser-mining approach as HASHPIXELS. CPU remains available only as a fallback. Nothing is submitted while searching. A valid win is verified again onchain, then the contract mints one random unused HASHCAT. Mint price is free; only a successful claim pays the fixed 1 USDC mining fee directly to treasury.
